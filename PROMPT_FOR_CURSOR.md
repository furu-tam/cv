Hãy push project CV này lên GitHub và public bằng GitHub Pages, làm đúng các bước sau và báo lại link cuối cùng cho tôi:

1. Kiểm tra trong folder này chỉ có file CV, không push file rác hay file nhạy cảm.
2. Tạo repo GitHub mới, tên gợi ý: `cv` (nếu tên này đã tồn tại thì dùng `dinh-minh-tam-cv`). Repo public.
3. Git init (nếu chưa có), add, commit với message rõ ràng, push lên nhánh main của repo mới.
4. Bật GitHub Pages: Settings > Pages > Deploy from a branch > nhánh main, thư mục / (root).
5. Chờ Pages build xong, kiểm tra link thật bằng trình duyệt xem trang có hiện đúng nội dung CV không, rồi báo lại cho tôi link GitHub Pages cuối cùng.
6. Không được sửa nội dung CV trong index.html, trừ khi cần sửa đường dẫn tương đối để Pages chạy được — nếu có sửa thì nói rõ đã sửa gì.
